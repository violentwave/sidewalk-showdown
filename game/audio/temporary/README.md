# Temporary audio picks

These are prototype assets, not the final soundtrack or sound-design pass. The
selected files are kept small and local so the current match can be evaluated
with actual sound. Replace or re-author them during the final audio pass.

All source assets below are CC0 1.0 (public-domain dedication); the sources
permit commercial use and require no attribution. Credits are included anyway.
